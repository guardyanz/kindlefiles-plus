# Security reporting

Please use [GitHub private vulnerability reporting](https://github.com/guardyanz/kindlefiles-plus/security/advisories/new) for a possible vulnerability. Do not include secrets or personal files in public issues.

FolderKit 0.9.0-rc2 is a public beta. File operations are scoped to Android's Storage Access Framework. Physical Fire tablet compatibility remains under testing. Use disposable fixtures when reproducing data-loss or provider failures.
