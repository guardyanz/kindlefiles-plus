# FolderKit privacy policy

- Effective date: 1 October 2026
- Publisher: Ribnik Studio
- Support: wardiyanto.skm@gmail.com

FolderKit for Fire tablets is a local file manager. It does not require an account, request internet access, include advertising or analytics SDKs, or send files, file names, or duplicate hashes to Ribnik Studio.

The app stores user-selected folder locations, labels, favorites, and widget configuration in private app storage. Android stores the storage permissions that users grant through the system picker. Duplicate hashes are computed locally and kept in memory only during a scan. Android backup for the app is disabled.

Users may choose **Share** or **Open with**. Android then grants the receiving app access to the selected file. A receiving app, including Kindle when installed, follows its own privacy practices. A storage provider chosen in the system picker may itself use a cloud service; choose local storage for local-only operations.

Users may remove a saved location inside the app. Clearing app data or uninstalling FolderKit removes its preferences and granted access. Files created in user-selected storage remain there. Deletion from FolderKit is permanent and requires confirmation.

Questions about this policy or the app can be sent to the support address above.
