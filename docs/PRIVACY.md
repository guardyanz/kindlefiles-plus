# Privacy

KindleFiles+ 0.1.0 runs file operations on the device. The application does not request internet access, use analytics or advertising SDKs, or require an account.

It stores folder URIs, labels, favorites, and widget configuration in private app preferences. Android stores the user's persisted URI permissions. Android backup is disabled. File contents and hashes are not sent to the developer. Duplicate hashes live only in memory during a scan.

Choosing Share or Open with grants the selected receiving application read access to the selected file. That application's privacy practices apply. Storage providers offered by Android may themselves use cloud services; select local folders to keep operations fully local. Amazon handles delivery when users explicitly share to Kindle.

Clear app data or uninstall to remove preferences and URI grants. Files that users created in shared storage remain on the selected storage. File deletion is permanent.

Before store publication, host this policy and add the publisher's public support contact. This draft does not imply a currently published app.
